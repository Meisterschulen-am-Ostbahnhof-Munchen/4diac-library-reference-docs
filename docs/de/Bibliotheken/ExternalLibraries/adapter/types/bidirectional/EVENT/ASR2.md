# ASR2

**Plug (Adapter-Ausgang)**

![ASR2_plug](ASR2_plug.svg)

**Socket (Adapter-Eingang)**

![ASR2_socket](ASR2_socket.svg)

bidirectional Adapter Interface for 2 Events

## Interface

### Event Inputs

| Name     | Comment            | With |
| :------- | :----------------- | :--- |
| EI_SET   | Set / Switch on    |      |
| EI_RESET | Reset / Switch off |      |

### Event Outputs

| Name     | Comment            | With |
| :------- | :----------------- | :--- |
| EO_SET   | Set / Switch on    |      |
| EO_RESET | Reset / Switch off |      |

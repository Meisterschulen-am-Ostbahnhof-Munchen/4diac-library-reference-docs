# A2X2

**Plug (Adapter-Ausgang)**

![A2X2_plug](A2X2_plug.svg)

**Socket (Adapter-Eingang)**

![A2X2_socket](A2X2_socket.svg)

bidirektionales Adapter-Interface für 2 Ereignisse und 2 Bools

## Interface

### Ereignis-Eingänge

| Name    | Kommentar                      | With    |
| :------ | :----------------------------- | :------ |
| EI_UP   | UP Anfrage (oder Indikation)   | DI_UP   |
| EI_DOWN | DOWN Anfrage (oder Indikation) | DI_DOWN |

### Ereignis-Ausgänge

| Name    | Kommentar                      | With    |
| :------ | :----------------------------- | :------ |
| EO_UP   | UP Indikation (oder Anfrage)   | DO_UP   |
| EO_DOWN | DOWN Indikation (oder Anfrage) | DO_DOWN |

### Eingangsvariablen

| Name    | Typ  | Kommentar                                                |
| :------ | :--- | :------------------------------------------------------- |
| DI_UP   | BOOL | TRUE = vorwärts, hoch, rechts, im Uhrzeigersinn          |
| DI_DOWN | BOOL | TRUE = rückwärts, runter, links, gegen den Uhrzeigersinn |

### Ausgangsvariablen

| Name    | Typ  | Kommentar                                                |
| :------ | :--- | :------------------------------------------------------- |
| DO_UP   | BOOL | TRUE = vorwärts, hoch, rechts, im Uhrzeigersinn          |
| DO_DOWN | BOOL | TRUE = rückwärts, runter, links, gegen den Uhrzeigersinn |

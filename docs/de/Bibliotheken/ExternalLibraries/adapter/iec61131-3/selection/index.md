# selection

In dieser Kategorie finden Sie Bausteine zur Signalauswahl und Extremwertbildung für Adapter-Schnittstellen:

- **[AR_AX_SEL_AR](./adapter/AR_AX_SEL_AR.md)**: Binäre Auswahl zwischen zwei AR-Eingängen basierend auf einem AX-Selektor.
- **[AR_MAX](./adapter/AR_MAX.md)**: Ermittlung des Höchstwerts (Maximum) aus zwei AR-Eingängen.
- **[AR_MIN](./adapter/AR_MIN.md)**: Ermittlung des Mindestwerts (Minimum) aus zwei AR-Eingängen.

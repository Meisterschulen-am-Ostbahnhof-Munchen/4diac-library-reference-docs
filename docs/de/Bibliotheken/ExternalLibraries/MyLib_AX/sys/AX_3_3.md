# AX_3_3

![AX_3_3_network](./AX_3_3_network.svg)

* * * * * * * * * *

## Einleitung

`AX_3_3` kombiniert `AX_OR_3` und `AX_SPLIT_3` zu einem fertigen Baustein: Drei `AX`-Quellen (`IN1`, `IN2`, `IN3`) werden per ODER zu einem gemeinsamen Signal verknüpft und anschließend auf drei Ziele (`OUT1`, `OUT2`, `OUT3`) verteilt.

## Verwendete Funktionsbausteine (FBs)

### Sub-Bausteine: AX_3_3

- **Typ**: SubAppType
- **Verwendete interne FBs**:
    - **AX_OR_3**: `adapter::booleanOperators::AX_OR_3` — verknüpft `IN1`/`IN2`/`IN3` per ODER.
    - **AX_SPLIT_3**: `adapter::events::unidirectional::AX_SPLIT_3` — verteilt das ODER-Ergebnis auf drei Ausgänge.
- **Funktionsweise**: `IN1`/`IN2`/`IN3` → `AX_OR_3.OUT` → `AX_SPLIT_3.IN` → `OUT1`/`OUT2`/`OUT3`.

## Programmablauf und Verbindungen

1. `IN1` → `AX_OR_3.IN1`; `IN2` → `AX_OR_3.IN2`; `IN3` → `AX_OR_3.IN3`.
2. `AX_OR_3.OUT` → `AX_SPLIT_3.IN`.
3. `AX_SPLIT_3.OUT1` → `OUT1`; `AX_SPLIT_3.OUT2` → `OUT2`; `AX_SPLIT_3.OUT3` → `OUT3`.

## Anwendungsszenarien

- Zusammenführen dreier `AX`-Quellen (z. B. drei Kommandowege), deren gemeinsames Ergebnis an drei unabhängige Ziele verteilt werden muss.

## Vergleich mit ähnlichen Bausteinen

Für andere Quellen-/Ziel-Anzahlen: [`AX_2_3`](./AX_2_3.md) (2→3), [`AX_3_2`](./AX_3_2.md) (3→2).

## Zusammenfassung

`AX_3_3` ist eine reine Verdrahtungshilfe, die drei `AX`-Quellen per ODER zusammenführt und auf drei Ziele verteilt — ohne eigene Zustandslogik.

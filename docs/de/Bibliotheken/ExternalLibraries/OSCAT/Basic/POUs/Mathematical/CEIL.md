# CEIL

Rundet eine Gleitkommazahl (`REAL`) auf die nächstgrößere oder gleiche ganze Zahl ab bzw. auf (`INT`).

## Interface

### Event Inputs

| Name | Comment | With |
| :--- | :------ | :--- |
| REQ  |         | X    |

### Event Outputs

| Name | Comment | With |
| :--- | :------ | :--- |
| CNF  |         |      |

### Input Vars

| Name | Type | Comment |
| :--- | :--- | :------ |
| X    | REAL | Eingangswert |

### Output Vars

| Name | Type | Comment |
| :--- | :--- | :------ |
|      | INT  | Kleinste ganze Zahl >= X |

# CEIL2

Rundet eine Gleitkommazahl (`REAL`) auf die nächstgrößere oder gleiche 32-Bit Ganzzahl (`DINT`) auf.

## Interface

### Event Inputs

| Name | Comment | With |
| :--- | :------ | :--- |
| REQ  |         | X    |

### Event Outputs

| Name | Comment | With |
| :--- | :------ | :--- |
| CNF  |         |      |

### Input Vars

| Name | Type | Comment |
| :--- | :--- | :------ |
| X    | REAL | Eingangswert |

### Output Vars

| Name | Type | Comment |
| :--- | :--- | :------ |
|      | DINT | Kleinste Ganzzahl (32-Bit) >= X |

# CEIL2

Rounds a floating point number (`REAL`) up to the smallest 32-bit integer greater than or equal to `X` (`DINT`).

## Interface

### Event Inputs

| Name | Comment | With |
| :--- | :------ | :--- |
| REQ  |         | X    |

### Event Outputs

| Name | Comment | With |
| :--- | :------ | :--- |
| CNF  |         |      |

### Input Vars

| Name | Type | Comment |
| :--- | :--- | :------ |
| X    | REAL | Input value |

### Output Vars

| Name | Type | Comment |
| :--- | :--- | :------ |
|      | DINT | Smallest 32-bit integer >= X |

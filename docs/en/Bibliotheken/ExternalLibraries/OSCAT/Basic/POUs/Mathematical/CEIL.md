# CEIL

Rounds a floating point number (`REAL`) up to the smallest integer greater than or equal to `X` (`INT`).

## Interface

### Event Inputs

| Name | Comment | With |
| :--- | :------ | :--- |
| REQ  |         | X    |

### Event Outputs

| Name | Comment | With |
| :--- | :------ | :--- |
| CNF  |         |      |

### Input Vars

| Name | Type | Comment |
| :--- | :--- | :------ |
| X    | REAL | Input value |

### Output Vars

| Name | Type | Comment |
| :--- | :--- | :------ |
|      | INT  | Smallest integer >= X |

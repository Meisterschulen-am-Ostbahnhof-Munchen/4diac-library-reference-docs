# A2X2

**Plug (adapter output)**

![A2X2_plug](A2X2_plug.svg)

**Socket (adapter input)**

![A2X2_socket](A2X2_socket.svg)

bidirectional adapter interface for 2 events and 2 bools

## Interface

### Event Inputs

| Name    | Comment                      | With    |
| :------ | :--------------------------- | :------ |
| EI_UP   | UP Request (or Indication)   | DI_UP   |
| EI_DOWN | DOWN Request (or Indication) | DI_DOWN |

### Event Outputs

| Name    | Comment                      | With    |
| :------ | :--------------------------- | :------ |
| EO_UP   | UP Indication (or Request)   | DO_UP   |
| EO_DOWN | DOWN Indication (or Request) | DO_DOWN |

### Input Vars

| Name    | Type | Comment                                        |
| :------ | :--- | :--------------------------------------------- |
| DI_UP   | BOOL | TRUE = forward, up, right, clockwise           |
| DI_DOWN | BOOL | TRUE = backward, down, left, counter-clockwise |

### Output Vars

| Name    | Type | Comment                                        |
| :------ | :--- | :--------------------------------------------- |
| DO_UP   | BOOL | TRUE = forward, up, right, clockwise           |
| DO_DOWN | BOOL | TRUE = backward, down, left, counter-clockwise |

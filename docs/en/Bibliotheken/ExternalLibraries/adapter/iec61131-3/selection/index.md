# selection

In this category, you will find function blocks for signal selection and extremum computation using adapter interfaces:

- **[AR_AX_SEL_AR](./adapter/AR_AX_SEL_AR.md)**: Binary selection between two AR inputs based on an AX selector.
- **[AR_MAX](./adapter/AR_MAX.md)**: Computes the maximum value from two AR inputs.
- **[AR_MIN](./adapter/AR_MIN.md)**: Computes the minimum value from two AR inputs.

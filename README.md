# 4diac Bibliotheken: FB- & Adapter-Referenz (4.1)

Ausgelagerte Function-Block- und Adapter-Referenz aus
[visual-programming-languages-docs](https://github.com/Meisterschulen-am-Ostbahnhof-Munchen/visual-programming-languages-docs)
(Wiki 4 „Visuelle Programmiersprachen: Low-Code"), als eigenes Wiki **4.1**.

Grund für die Auslagerung: Das ursprüngliche `Bibliotheken/`-Verzeichnis enthält
über 7.000 automatisch generierte Dateien (Function Blocks, Adapter, SVG-Diagramme)
und hat den ReadTheDocs-Build von `visual-programming-languages-docs` auf
über 13 Minuten pro Sprache aufgeblasen (Zeitlimit-Timeouts). Als eigenständiges,
seltener neu gebautes Projekt bleibt die Bauzeit beherrschbar.
